# DoctorCoach Premium UI 3 — בדיקת אינטגרציה ומוכנות

תאריך: 30.10.2026. מקור UI: PR #63, `bc635ff5fd07939f8f7d3a9ece623606da93ea56`. בסיס אינטגרציה: PR #62, `5d5284f55677017459e63252f24199aa4bd486f8`. תיקוני הבדיקה והביצועים נמצאים ב־PR #64, המכוון לענף #63. שום PR לא מוזג.

## מה נבדק ומה תוקן

נבדקו ששת קומיטי #63 ו־34 הקבצים ששונו בו: מעטפת וניווט, עיצוב משותף, דף הבית וחיבור נתוניו, טיימר, תרגום, ערכות צבע, fixtures ובדיקות CI. נבדקו גם קובצי הבסיס הרלוונטיים לאחסון, הרשאות, ייעוצים ו־Calendar. בסיס #62 הוא ancestor של #63; השילוב אינו דורש פתרון התנגשויות. לא נוספו שינויים לחוזי API, מיגרציות, חבילות או lockfiles.

תיקונים בסבב הנוכחי:

1. תנאי CI השמיטו את ענף Premium UI ואת יעד האינטגרציה. ההרצה הירוקה `41065210319` דילגה בפועל על consultation/management/import/cardio/anatomy browser workflows. נוספו תנאים לענף המקור ולענף היעד, וכן ארבע בדיקות אירועי GitHub. שלוש בדיקות נכשלו לפני התיקון; כולן עברו אחריו. בדיקה רביעית שומרת על הסינון בענפים שאינם קשורים. זו בעיית כיסוי, ולא הוכחה לתקלה בתהליכי המוצר.
2. מטריצת המסכים נטענה קודם ללא תשובת appearance של חשבון, ולא הפעילה מצב בהיר מפורש. נוספה תשובה סינתטית התואמת לחוזה הקיים, המתנה למצב הצבע בפועל, והרצה בבהיר ובכהה. נשמרו בדיקת צבע הכפתור בפועל, overflow, טיימר וחסימת אימון.
3. fixtures של ספריית התרגילים/פרטי התרגיל לא סיפקו media, ולכן חלק מהצילום הציג שער כניסה במקום מצב טעון. נוספה תשובת media ריקה תקינה, ונוספה בדיקה שפרטי התרגיל אינם מציגים שער כניסה. אין כאן וידאו בדוי.
4. נוספו צילומי דשבורד מאמן וניהול משתמשים בתוך מעטפת האפליקציה המלאה; בדיקות הרכיבים הנפרדות אינן מספיקות כדי לבדוק את CSS המעטפת.
5. תמונת הבית הקדמית ירדה מ־1,926,581 bytes ל־139,000 bytes באמצעות WebP באותן מידות 1536×1024 ובאותו תוכן. חיסכון של 92.8% בהעברה של משאב זה, ללא טענה לשיפור מדוד בזמן טעינת העמוד. המקור נשמר. בדיקת תקציב 250 KiB נכשלה לפני התיקון ועברה אחריו.

6. תוקנה התנגשות CSS במצב בהיר: כללי דף הבית הוותיקים צבעו את כותרת ה־Hero בשחור על תמונה כהה, וברוחב 320/375 שכבת הרקע נגזרה מהרקע הבהיר. משתני צבע מקומיים ל־Hero שומרים על טקסט בהיר ועל שכבה כהה, בלי לשנות את ערכת החשבון. בדיקת הדפדפן החדשה נכשלה לפני התיקון (run 41069455688). נוספה גם בדיקת ניגודיות לטקסט הניווט הפעיל: הצבע הישן נתן 1.50:1 מול רקע הניווט הבהיר; טוקן הפעולה הקיים נותן 4.51:1.
7. הבדיקה המורחבת חשפה selector ישן של כפתור ייעוץ (`.dc-premium-consult button`). הבדיקה עברה לכפתור הנגיש `Open consultations`, עם המתנה למסך היעד. לא הוסרה בדיקת הניווט (כשל משוחזר בריצה 41067756976).
8. נוספה בדיקת React מלאה מול SQLite מבודד: שמירת סט עם משקל/חזרות/RPE, e1RM והמלצת הסט הבא, עריכה, טעינה מחדש, סיום אימון חלקי והופעה בהיסטוריה. המסלולים נבדקים בעברית/אנגלית וב־390/1440 בשני מצבי הצבע. אימות זה אינו מחליף את בדיקת auth/הרשאות ב־Worker. ריצה ראשונה השלימה את מסלול HE/390 ונכשלה במעבר למסד הבא בגלל ניווט hash שאינו מרענן את controller; נוסף reload מפורש בין מסדים, ללא שינוי קוד המוצר.

9. בדיקת הפלטות שמרה על מגבלת גובה Hero במחשב וחשפה גדילה של השורה ל־391.6px לאחר הוספת ארבע הטבעות. קוטר הטבעות הוגבל ל־112px במחשב בלבד, כדי לשמור על פריסה קומפקטית במסגרת הבדיקה המקורית; לא הוגדל סף הבדיקה.

לא בוצעו שינויים בהתנהגות רפואית, חישובי אימון, מדיניות הרשאות או guards של חיוב. תיקון בדיקות סוף־החודש ב־#63 משתמש בשעוני JavaScript/SQLite סינתטיים, כולל בדיקה שה־DB ממשיך לחסום בקשת הסרה כאשר שעון האפליקציה מיושן. תיקון תזמון הייעוצים ממתין למועד שנשמר לפני פתיחת הביטול.
