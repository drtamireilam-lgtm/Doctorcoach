## Exercise library and exercise intelligence

[Exercise inventory](exercise-inventory.csv) covers 184 IDs including 32 workout-section stretches. It records both names, alias strings, actual program-import resolutions, primary muscles, assisting muscles, stabilizers, stretch targets, drill cues, missing role geometry and dedicated motion joints. Blank values mean the inspected data source supplied no value. [Alias collisions](alias-collisions.csv) contains all 28 cross-ID sorted-word keys in the combined name/ID/alias index. Default strict matching and program import use different general-movement eligibility rules. The inventory exercises the program policy. The catalog has unique IDs and Hebrew names, and every row has at least 15 aliases.

The original English names of the graded calf raise and barbell overhead press duplicated the corresponding generic movements. Copying their English names into program import selected the generic ID. The corrected public labels select the specific IDs in English and Hebrew. Legacy spellings remain aliases. One overlap still warrants an editorial choice. The source Reverse Fly allows machine execution or chest support, while literal program import picks movement-rear-delt-fly. Decide whether to narrow the specific variant or keep both available as explicit choices. Retain historical IDs throughout.

Unlinked imports already retain the original text, suppress demo requests and support later coach linking. The existing unlinked-import-demo tests cover those three behaviors. #109–110 also covered import display and unmapped populated columns. Generic movement records have deliberately unspecified equipment. Sixteen have no technique cues. A LAB video can show only one execution of a generic label. Identify that example in both languages on generic cards, especially movement-leg-curl and movement-chest-press, before treating a filmed setup as a prescription.

After the proposed updates there are 265 primary, 149 secondary, 60 stabilizer and 41 stretch relationships. Thirteen IDs have no structured role or target. Nine exercises have at least one authored link without matching detailed geometry. All records and IDs are in the inventory. Four stretches still need precise target selection: Cossack squat stretch, posterior neck stretch, pole-supported upper-back stretch and knee-to-opposite-shoulder stretch. Their text describes a region or compound movement. Add variant-specific evidence and retain uncertainty until reviewed. The role type has no antagonist field. Dedicated exercise-motion joint metadata in anatomy-exercise-motion.ts covers barbell-curl only. Joint lesson playback is a separate feature. Add phase-specific joint action, plane, optional antagonist, technique source and review status per variant. Never infer a single plane or antagonist from a muscle list.

[Public LAB media](lab-media.csv) lists all 185 video/poster paths, sizes, digests and stream metadata. Every asset returned HTTP 200. MP4 and WebP signatures matched. Every video size matched the manifest. ffprobe identified 185 H.264 streams lasting 4.4–8 seconds. No repeated video or poster digest was found. All 185 posters were screened as contact sheets. Three sampled positions were additionally inspected in sit-stand, trap-bar-deadlift, step-up and hip-hinge-dowel. Chair, hex bar, step and dowel respectively were visible in those samples. This pass found no confirmed swapped files. Per-repetition motion, side, grip, joint travel and muscle-color adjudication across the full set remain open. The source branch cannot reproduce the full LAB media inventory.

## Atlas coverage

[Muscle inventory](anatomy-inventory.csv) compares all 136 educational muscle IDs across 16 model manifests. 100 IDs have direct or parent-context links in the detailed model after the change. An unmatched educational ID can represent an aggregate, a differently named mesh, a subdivision, or unavailable geometry. The asset contains 634 structures across all tissues. All generated structure metadata was verified against the pinned source. Placement, scale and inter-layer registration still require anatomical review. Upstream geometry is simplified, displaced for layering and mirrored.

| Structure | Detailed atlas evidence | Action |
|---|---|---|
| Rectus abdominis | Separate left and right, superficial; card and role links | Test discoverability from the regional torso screen and low cobra. |
| External and internal obliques | Two nodes each; superficial and deep respectively | Keep lateral wall order clear on the selection panel. |
| Transversus abdominis | Two deep nodes linked to its card | Distinguish it from internal oblique within the broad deep filter. |

| Shoulder and hip stabilizers | Bilateral linked nodes include supraspinatus, infraspinatus, teres minor, subscapularis, serratus anterior, gluteus medius/minimus, obturator internus and piriformis | Verify side and visibility under overlapping muscles for each representative exercise. |
| Diaphragm and pelvic floor | No resolved detailed link to either educational ID | Inspect source elements and scope before admitting geometry. Pelvic floor is a group. |

Regional torso and spine assets do not have the same coverage as the detailed atlas. There is no evidence for adding duplicate rectus, transversus or QL geometry to the latter. Two source depth buckets do not encode each abdominal wall plane. The intended anatomical relationships can be checked against [NCBI anterior wall anatomy](https://www.ncbi.nlm.nih.gov/books/NBK525975/) and [NCBI quadratus lumborum anatomy](https://www.ncbi.nlm.nih.gov/books/NBK535407/).

## Prioritized Codex backlog

1. **P1 · Reconcile release provenance.** Locate the source and build containing smith-incline-bench and all 185 video/poster pairs. Generate an immutable manifest tying Worker build, catalog, atlas digest and media digests together. Rebuild locally and compare against lab-media.csv. Preserve the 185 working pairs. Review the patch against that tree before release.
2. **P1 · Finish exercise-to-muscle coverage.** Work the 13 flagged IDs and nine geometry gaps from the CSV. Start with the four missing stretch targets. Use exact IDs, documented cue, clinical source and review state. Check both directions and missing-geometry feedback automatically. Preserve legitimate group targets.
3. **P1 · Make trunk anatomy discoverable.** Add a clear regional-to-detailed entry point with side, selected structure, depth and camera position. Verify rectus, both obliques, transversus and QL in each language at 390 px. Document a front, lateral or posterior landmark for each. Verify cervical/thoracic routes before expanding multifidus links.
4. **P2 · Review exercise intelligence and media by variant.** Start with overhead press, reverse fly, bench variants and generic machine movements. Record equipment, joint actions and planes by phase, relevant antagonists, intended muscles, cues and timestamp evidence. Show generic clips as examples. Record approvals per variant and clip digest.
5. **P2 · Complete synthetic mobile journeys.** Exercise selection → edit and replace → log yesterday → correct an RPE → confirm timeline and historical plan snapshot. Run HE/EN at four mobile/tablet widths plus native Safari when available. Include offline/retry, zero-history state and duplicate prevention.
6. **P2 · Close recovery evidence.** Reconcile retained backup receipts with the exact release data boundary and isolated restore verification. Report stale, missing or inaccessible evidence explicitly. This audit grants no release or production-change approval.
7. **Later pilot.** Measure whether trainees independently find a deep muscle, choose the intended variant and recover an interrupted workout. This is a usability outcome and independent engineering work can proceed immediately.
