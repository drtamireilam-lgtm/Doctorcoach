# DoctorCoach body navigator and arm atlas

Continues the live shoulder from branch `feature/anatomy-asset-safety-stage36`, base `8cccfcdbfed3c1dd3347dd2ced66bc443b9a0821`. The existing Smart Load branch through `49969c3` is preserved. No database migration or permission change is introduced.

## Implemented

- Real whole-body navigation surface, 488,488 bytes / 24,000 triangles. Region selection by raycasting or accessible selector; approximate navigation zones are explicitly distinguished from anatomical boundaries. Head is context only. Other regions open learning content with an explicit missing-model notice.
- Right arm/elbow/forearm model, 933,416 bytes / 46,390 triangles: scapula, humerus, radius, ulna, biceps brachii (two heads), triceps brachii (three heads), brachialis and brachioradialis. This is a selected-structure subset, not all forearm anatomy. Separate joints, tendons, ligaments, nerves and hand geometry are absent.
- Existing right shoulder and its 12 mapped structures retained. Shared viewer supports rotation, mouse/touch zoom, camera presets, layer visibility, isolation, clear/reset and camera/selection restoration when returning from an exercise.
- Existing bilingual learning cards and canonical exercise relationships reused. Added source-checked innervation summaries for the four new modeled muscles. Reverse links select modeled muscles; an unmodeled muscle retains its learning card and never substitutes another mesh.
- Models load on demand, one active WebGL scene. Downloads undergo SHA-256, byte-budget and exact mesh-inventory checks. Abort/unmount frees geometries, materials, controls, listeners, observer, renderer and WebGL context. Pixel ratio remains capped; rendering occurs on changes, without an animation loop.
- Main app integration remains gated to explicit local development / isolated LAB targets. Existing navigation, authentication, permissions, themes, exercise library and workout features are preserved.

## Asset provenance and content

BodyParts3D 4.0, The Database Center for Life Science (DBCLS). Official archive: https://dbarchive.biosciencedbc.jp/data/bodyparts3d/LATEST/isa_BP3D_4.0_obj_99.zip . Official mapping: `LATEST/isa_element_parts.txt`.

Current official license evidence: https://dbarchive.biosciencedbc.jp/en/bodyparts3d/lic.html — CC BY 4.0, allowing commercial redistribution and modification with attribution. Required attribution is included in each manifest and viewer: “BodyParts3D, © The Database Center for Life Science licensed under CC Attribution 4.0 International”.

The body uses original skin ELEMENT `FJ2810`, simplified using fast-simplification 0.1.13. Spatial partitions are approximate navigation aids. Arm ELEMENT IDs are explicitly listed in `scripts/anatomy/build-atlas.py`. Original source hashes, mapping rows, modifications and final asset hashes are recorded in `lib/prepared/{body,arm}-model.json` and public attribution manifests. No anatomy was synthesized. The converter dependency is offline build tooling, not a web runtime dependency.

The four new muscle summaries were checked against UAMS's upper-limb muscle table: https://medicine.uams.edu/neuroscience/education/medical-school-courses/human-structure-module/anatomy-tables/muscle-tables/muscles-of-the-upper-limb/ . This is source checking, not clinical validation. Geometry/labels require clinician review. No comparison against licensed Netter/Sobotta/Gray illustrations was performed and no such illustrations were copied.
