# רשימת בדיקה אנטומית — DoctorCoach 3D LAB

תאריך הכנה: 18.10.2026. בודק: תמיר / איש מקצוע מוסמך.

**כל הסעיפים ממתינים לבדיקה. מסמך זה אינו אישור רפואי.**

## איך לבדוק

1. הפעל `npm ci` ואז `npm run anatomy:dev` ופתח את `anatomy-lab.html`.
2. בחר כל שריר ברשימה. בדוק גם מבט קדמי וגם אחורי. עבור לשרירים עמוקים, הסתר את השכבה השטחית.
3. בדוק את הטקסט מול מקור אנטומי מוסמך. תקן במפורש מה חסר או שגוי; סמן מאושר רק לאחר התיקון.
4. בדוק את ההדמיה בנפרד מהטקסט. כרגע הצורה היא גוף אליפטי סכמטי, ללא גידים ונקודות אחיזה אמיתיות. אין לאשר אותה כמודל הוראה רק מפני שהטקסט נכון.
5. תעד שם בודק, תאריך, מקור, תיקון ומזהה commit לכל אישור.

## בדיקת הרחקת כתף

- [ ] הרחקה נבדלת מכפיפה ומסיבוב הזרוע.
- [ ] דלתא אמצעית ועל־קוצי מוצגים עם תיאור תפקיד שאינו בלעדי.
- [ ] טרפז ו־serratus anterior מתוארים כתורמים לתנועת השכמה; serratus טרם מודל.
- [ ] תנועת שכמה ובריח, ציר מפרק וסיבוב הומרוס — **אינם מודלים כרגע**.
- [ ] צבע ההדגשה אינו מפורש כמדידת EMG, כוח או הפעלת שריר מדויקת.
- [ ] אין טענה שהאליפסות משקפות התכווצות/מתיחה אמיתיות.
- [ ] יש סימון גלוי שהטווח 0–90° הוא הדגמת ממשק ולא המלצת שיקום.

טקסט: ☐ דורש תיקון ☐ מאושר לאחר בדיקה מתועדת
