# General movements and optional implements

User decision, 25 October 2026: an exercise name without an implement must remain a general exercise, without asking the coach to select cable/dumbbell/machine. Explicit equipment must be preserved. Hammer-branded pulling/rowing names from the source refer to machines. Research unfamiliar named movements instead of leaving them unresolved merely because absent from the catalog.

Implementation choice: extend the existing canonical catalog with general parent movements; preserve all existing variant IDs. Reuse the existing implement-neutral overhead-triceps record rather than duplicating it. Program import explicitly opts into literal general-parent precedence; strict matching evaluation remains on its original contract and excludes new parent IDs. Spelling similarity never guesses new parent movements.

Implement is optional in the existing per-exercise notes editor, labeled bilingually Equipment and exercise notes (optional). This avoids parallel persistence and any database migration; this is currently a shared free-text field, not a structured equipment selector. Explicit variant names still match their existing IDs. Historical variant data is not migrated or combined with general-parent history.

Kelso Shrug has its own canonical entry, distinct from vertical shrugs: chest-supported scapular retraction. Sources researched: Eirik Sandvik's original descriptions, https://archive.t-nation.com/training/tip-do-kelso-shrugs-for-complete-trap-development/ and https://archive.t-nation.com/training/tip-the-kelso-shrug-for-traps-and-back/ . Hammer machine context confirmed against https://www.lifefitness.com/en-us/brands/hammer-strength . Do not interpret the brand alone as identifying a particular model or movement direction.

No equipment is inferred for general movement names. Source placeholders such as Legs 1/Legs 2 and instructions requesting two exercises cannot be identified from web research and must not be falsely assigned. No OCR, AI guessing, production data changes or deletion. General parents do not manufacture demos or anatomy links.
