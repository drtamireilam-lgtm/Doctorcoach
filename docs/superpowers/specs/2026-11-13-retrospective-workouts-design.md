# Retrospective workouts — approved design

Approved in conversation 13 November 2026. Add a shared mobile-friendly screen for logging a workout from the current program or freely chosen exercises, including a private free-text exercise. Select a past or present Israel calendar date. Keep performed date distinct from recording timestamp; do not infer duration from editing time. Preserve missing repetitions, load, effort and pain as unknown. Allow changing the performed exercise list without mutating the prescribed plan. Preserve occurrence identity and original prescription snapshots. Save/reload a private server draft; warn on existing completed workouts that day and require explicit acknowledgement. Integrate completed records into the existing history, weekly counts and performance charts by performed date. Preserve existing access, consent and medical gates. Do not modify live data, merge, migrate remotely or deploy.

Approach: reuse canonical training_sessions for completed historical entries with explicit retrospective metadata; separate versioned draft table. A separate disconnected history was rejected because coaches/charts would miss records; pretending the workout happened when entered was rejected because it corrupts dates and duration. Build on PR74 head to retain its localization corrections. Historical imports use the current authorized program, labeled as such, not an invented historical prescription.
