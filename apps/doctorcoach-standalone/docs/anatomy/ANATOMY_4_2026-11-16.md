# Anatomy 4.0 implementation matrix — 2026-11-16

## Scope and reused baseline

Extend the existing anatomy branch locally. No deployment, merge, or asset replacement is authorized by this implementation. The reused combined scene baseline is 201 bones and 178 muscle meshes (89 bilateral muscle groups); these are scene meshes, not a claim that every human bone or muscle is individually modeled. Existing regional models, canonical muscle slugs, bilingual learning cards, exercise IDs, video/detail flows, and attribution metadata remain the foundation.

| Missing anatomy | Some canonical learning cards have no mesh or exercise | Keep honest empty states; do not synthesize geometry or relationships |

## Exercise implementation

`lib/anatomy-exercises.ts` combines existing active and stretch relationships without duplicating an exercise/muscle pair. `components/anatomy-exercises.tsx` shows bilingual roles and a local exercise-type filter. `ExerciseAnatomyLinks` adds the current exercise ID to anatomy links. `AnatomyWorkspace` resolves context through the existing catalog, shows its bilingual name and a return button, and uses the unified list for the selected muscle. Hash context does not grant permissions, prescribe a program, or automatically execute an exercise.
