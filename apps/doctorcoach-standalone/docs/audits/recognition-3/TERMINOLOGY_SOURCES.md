# Generic squat and pullover naming evidence

Reviewed 26 October 2026. These sources support terminology only; their exercise advice was not copied or adopted. Other dictionary entries are literal paraphrases, transliterations, abbreviations and inflections of the existing catalog, with six separately recorded observed workbook names in `reviewed-import-aliases.ts`.

- [Sportal's own squat guide](https://www.l-sportal.co.il/%D7%90%D7%99%D7%9A-%D7%9C%D7%A2%D7%A9%D7%95%D7%AA-%D7%AA%D7%A8%D7%92%D7%99%D7%9C%D7%99-%D7%A1%D7%A7%D7%95%D7%95%D7%90%D7%98-%D7%9B%D7%9E%D7%95-%D7%A9%D7%A6%D7%A8%D7%99%D7%9A/): Hebrew squat vocabulary includes שפיפה and exercise/plural forms, plus כריעת סקווט. These names do not specify a barbell, machine or squat depth. Standalone כריעה is excluded because it can mean kneeling.
- [Israeli climbing association's training article](https://wiki.imga.org.il/index.php?title=%D7%AA%D7%9B%D7%A0%D7%99%D7%AA_%D7%90%D7%99%D7%9E%D7%95%D7%9F_%D7%9C%D7%98%D7%99%D7%A4%D7%95%D7%A1): directly uses the gym transliteration סקוואטס for squats. Only the lexical name was used, not the article's stance/depth advice.
- [Motra's own pullover catalog](https://www.motra.com/exercises/barbellPullOver): lists Lat Pullover and Chest Pullover as common names. Those bare names do not themselves specify a barbell, so this dictionary assigns them only to the general pullover parent, never inferring that article's implement. Hebrew muscle-target equivalents remain implement-neutral.
- [Decathlon's own Hebrew resistance-band page](https://www.decathlon.co.il/p/360481-227723-%D7%A8%D7%A6%D7%95%D7%A2%D7%AA-%D7%94%D7%AA%D7%A0%D7%92%D7%93%D7%95%D7%AA-%D7%9C%D7%90%D7%99%D7%9E%D7%95%D7%A0%D7%99-%D7%9B%D7%95%D7%97-20-%D7%A7%D7%92-%D7%A6%D7%94%D7%95%D7%91.html): uses the Hebrew plural פול-אוברס with a back target; this supports common plural/transliteration forms. Naming evidence is not permission to treat an explicitly banded pullover as a different catalog implement.

Safety regressions keep explicit Cable Pullover on the existing cable-specific ID and leave unknown decline/barbell pullover, Hindu squat and depth-specific knee-bend terms for review. No new catalog IDs or hidden implement assumptions were added.
